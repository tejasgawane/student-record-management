
# Student Record Management System

My first C programming project as a first-year student at Vidyalankar College.

## Features
- Add student records
- View all students
- Search by roll number
- Calculate average marks
- Validate marks and roll numbers

## Technologies
- C programming
- Structures
- Functions
- Arrays
- Loops and conditional statements

## How to Run

Compile using Clang:

```bash
clang -std=c11 -Wall -Wextra student_management.c -o student_management
```

Run on macOS:

```bash
./student_management
```
